# Web3 Copy Rules

## Voice defaults
Confident, specific, short. Write like a sharp founder, not a press release. Earn every word.

## Formulas that work
- **Outcome + mechanism:** "Get paid in minutes. Settled on Celo."
- **Number + benefit:** "$0.001 fees. Send to anyone with a phone number."
- **Before → after:** "From 3-day wires to 5-second transfers."
- **Event + urgency (real only):** "Mainnet is live. Bridge in today."
- **Identity (culture):** "Built by degens, for degens." Use only when it matches the community.

## Headline checklist
2–7 words, concrete, and verb-led or number-led. It works without context, and it passes the swap test.

## Words and phrases to avoid
revolutionary, next-generation, game-changer, seamless, cutting-edge, empower, unleash, the future of X,
Web3 for everyone, disrupt, synergy, moon, guaranteed, risk-free, passive income, 100x.

## Native vocabulary (use correctly, only for the right audience)
| Term | Use with | Note |
|---|---|---|
| mainnet / testnet | everyone | Say "Live on mainnet" only if true |
| non-custodial / self-custody | DeFi, wallets | A real trust signal. Explain simply for mainstream audiences |
| gasless | payments, consumer | Strong benefit. Mainstream users don't need to know the word "gas" |
| airdrop / points / season | traders, community | Never imply guaranteed value |
| TVL, APY, LTV | DeFi | Only with provided numbers. Label APY as variable |
| stablecoin / dollars | payments | For mainstream users, prefer "digital dollars" or just "dollars" |
| onchain | builders, natives | One word, lowercase is the modern convention |
| x402 | builders, AI agents | HTTP-native payments. "Pay per request, no accounts" |
| $TICKER | traders | Always uppercase with $ |

## CTAs
Pick one primary CTA per asset: "Try it", "Start sending", "Join the waitlist", "Read the docs",
"Mint now", "Claim your spot", or "Follow for launch".

## Captions for distribution (when asked)
- **X:** hook in the first line, under 280 characters, at most 1–2 hashtags (often zero), a link or handle at the end.
- **Telegram:** short paragraphs, emoji bullets are fine, a clear CTA link.
- **Instagram:** strong first line, value in the body, 3–5 relevant hashtags at the end.
